# 死锁产生的四个必要条件

> 四个条件同时满足才死锁:互斥、占有且等待、不可抢占、循环等待。破环任意一个即可避免死锁。

## 核心概念

1. **互斥**:资源一次只能被一个线程占用
2. **占有且等待**:占着资源不释放,同时等待别的资源
3. **不可抢占**:别人不能抢走自己持有的资源
4. **循环等待**:A 等 B,B 等 A,形成环路

## 例子

```java
// 线程1持锁A等锁B;线程2持锁B等锁A → 死锁
synchronized (lockA) { synchronized (lockB) { /* ... */ } }
synchronized (lockB) { synchronized (lockA) { /* ... */ } }
```

## 我的理解

最实用的破环手段:**破坏循环等待**——所有线程按同一顺序加锁(先 A 后 B),"破坏占有且等待"——一次性申请全部资源。
