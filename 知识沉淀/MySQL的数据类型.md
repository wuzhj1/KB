## 整数类型
| 类型       | 字节数 | 有符号范围()    | 无符号范围        | 典型用途      |
| -------- | --- | ---------- | ------------ | --------- |
| TINYINT  | 1   | -128 ~ 127 | 0 ~ 2^8 - 1  | 状态标志（0/1） |
| SMALLINT | 2   | -32K ~ 32K | 0 ~ 2^16 - 1 | 小型计数      |
| INT      | 4   | -21亿 ~ 21亿 | 0 ~ 2^32 - 1 | 主键、常规计数   |
| BIGINT   | 8   | ±9.2×10¹⁸  | 0 ~ 2^64 - 1 | 大ID、雪花算法  |

## 浮点与定点
| 类型           | 说明        | 典型用途        |
| ------------ | --------- | ----------- |
| FLOAT        | 单精度，有精度丢失 | 科学计算        |
| DOUBLE       | 双精度，有精度丢失 | 科学计算        |
| DECIMAL(M,D) | 定点数，精确存储  | **金额、财务数据** |

## 字符串类型
| 类型         | 说明           | 典型用途      |
| ---------- | ------------ | --------- |
| CHAR(N)    | 定长，0-255字符   | MD5值、国家代码 |
| VARCHAR(N) | 变长，0-65535字符 | 用户名、标题    |
| TEXT       | 大文本          | 文章内容、评论   |

## 时间类型
| 类型        | 格式                  | 范围         | 典型用途    |
| --------- | ------------------- | ---------- | ------- |
| DATE      | YYYY-MM-DD          | 1000-9999年 | 生日、日期   |
| DATETIME  | YYYY-MM-DD HH:MM:SS | 1000-9999年 | 业务时间    |
| TIMESTAMP | 同上                  | 1970-2038年 | 创建/更新时间 |
